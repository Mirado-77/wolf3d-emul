# Wolf3D Emulator — Le Palais du Crépuscule

Browser port of my Epitech wolf3d raycaster (C/CSFML), running on the game's own assets:
map, entities, textures, animated sprites, HUD and the fog formula from the original shaders.

## Run

```sh
npm install
npm run dev
```

## Controls

ZQSD / WASD move · arrows or mouse drag to turn · Shift sprint · E / Space / click cast ·
F open door · R torch · L / M drink potion · Enter restart
